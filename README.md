# NGLG Regalia Configurator — v1.4

Διαδραστικός ελληνικός οδηγός τεκτονικής περιβολής της ΕΜΣΤΕ, σε ένα αυτόνομο `index.html`.

## Live page

[Ανοίξτε το NGLG Regalia Configurator](https://webappngdsib.github.io/NGLG-DRESS-CODE/)

## Προεπισκόπηση
Ανοίξτε το `index.html` σε browser. Η βασική φιγούρα παραμένει σταθερή (μαύρο κοστούμι, λευκό πουκάμισο, μαύρη γραβάτα, μαύρες κάλτσες και παπούτσια). Οι εικόνες είναι προαιρετικά διαφανή overlays, που επιλέγονται ξεχωριστά για κάθε βαθμό/αξίωμα. Η εικόνα της φιγούρας είναι προσωρινή σχηματική απεικόνιση.

## Κατηγορίες
- Συμβολική Στοά
- Επαρχιακή Μεγάλη Στοά
- Μεγάλη Στοά
- Πρώην Μεγάλοι Αξιωματικοί
- Βασιλική Αψίδα (επιλογή μόνο μετά τον Διδάσκαλο)

## Builder
Εισαγωγή προαιρετικών αρχείων εικόνας για γραβάτα, περίζωμα, πρόσθετο διάσημο, περιλαίμιο, κόσμημα, Τάξη του Μεγάλου Διδασκάλου και **3 ανεξάρτητα κοσμήματα πέτου**. Κάθε κόσμημα πέτου έχει ρυθμίσεις οριζόντιας/κατακόρυφης θέσης (%), μεγέθους (%) και περιστροφής (°), καθώς και επιλογή 0–3 ενεργών θέσεων.

Οι φωτογραφίες και οι ρυθμίσεις κρατούνται μόνο όσο η σελίδα είναι ανοικτή. Η «Εξαγωγή ρυθμίσεων JSON» εξάγει τα δεδομένα, αλλά δεν δημοσιεύει μόνη της τις εικόνες στο GitHub Pages.

## Προδιαγραφές κοσμημάτων πέτου
- 1500 × 1500 px προτεινόμενο, τουλάχιστον 1000 × 1000 px.
- Μετωπική λήψη του κοσμήματος μόνο του, ουδέτερο φως, πιστά χρώματα.
- Αρχική λήψη σε ομοιόμορφο λευκό (#FFFFFF), τελικό PNG/WebP με **διάφανο φόντο**.
- Περιθώριο 5–10% και **όχι** φωτογραφία καρφιτσωμένη σε σακάκι.
- Προκαθορισμένη θέση στο **αριστερό πέτο του κυρίου**, δηλαδή **δεξιά για τον θεατή**. Οι θέσεις είναι παραμετρικές και ενδεικτικές, όχι κανονιστική οδηγία της ΕΜΣΤΕ.
- Ονόματα αρχείων ενδεικτικά: `pin_nglg.png`, `pin_royal_arch.png`, `pin_past_master.png`.

## Δημοσίευση
Το `index.html` μπορεί να δημοσιευθεί ως GitHub Pages από τον κύριο κλάδο του repository. Ο ιστότοπος δεν είναι ακόμη επίσημος κανονισμός περιβολής.
